Rule readings by preset
=======================

How each preset reads each rule, relative to the rule's text. See
:doc:`configuration` for the presets and :doc:`options` for the named options
behind a departure.

- ``as_written``: the rule as CERT writes it. Strict is always this.
- ``narrowed``: default reports less than strict, for a clear and common idiom.
- ``widened``: default reports more than strict (a reading by the rule's spirit,
  or an open family inferred wider).
- ``stricter``: pedantic's closed reading beyond strict.
- ``not_enforced``: the preset declines the rule, loudly, rather than guess.
