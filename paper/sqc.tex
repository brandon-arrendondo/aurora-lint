\begin{abstract}
Static analysis tools for C either cover narrow subsets of known
vulnerability classes or require heavyweight build infrastructure that
limits adoption.  This paper presents SqC, a static analyzer that
checks C source code for compliance with 311 rules from the SEI CERT C
Coding Standard---significantly broader coverage than any single
open-source alternative.  SqC uses tree-sitter for incremental parsing,
constructs per-function control-flow graphs, performs forward dataflow
analysis for null pointer state tracking, and employs inter-procedural
function summaries to reduce false positives across translation units.

We evaluate SqC against the NIST Juliet Test Suite v1.3 (50,256 test
files across 79 CWE categories) and 9 real-world open-source C codebases
totaling 1.21 million lines of code.  Through iterative
refinement---including cross-file function summaries, value-range analysis,
and CFG-based dead-branch pruning---the true positive rate improved from
41.1\% to 87.7\%, with 44 of 79 CWEs achieving 100\% precision (zero
false positives).  On a five-tool comparison against cppcheck, clang-tidy,
Infer, and Frama-C, SqC covers 5--13$\times$ more CWE categories while
now exceeding clang-tidy outright on three of fifteen overlapping CWEs
(integer overflow/underflow and integer-overflow-to-buffer-overflow) and
exceeding Frama-C's per-CWE precision on overlapping CWEs.  On real-world code, SqC detects
vulnerability classes---including POSIX misuse, integer overflow, and
inter-procedural null dereference---that cppcheck and clang-tidy do not
cover.
\end{abstract}
